
## AML-приоритизация

| компонент                      | тип                             | ответственность                                                    | не делает                                                       |
| ------------------------------ | ------------------------------- | ------------------------------------------------------------------ | --------------------------------------------------------------- |
| Event Ingestion & Validation   | Обычный код                     | Schema validation, idempotency, лимиты, quarantine/DLQ             | Не оценивает подозрительность                                   |
| Feature Pipeline / Store       | Обычный код/данные              | Point-in-time join, окна, freshness, offline/online parity         | Не использует будущие исходы                                    |
| Data Quality / OOD Gate        | Обычный код + статистика        | Missing/stale, cold start, диапазоны, OOD и область применимости   | Не заменяет финмониторинг                                       |
| Model Adapter                  | **Модель**                      | Ranking/anomaly score по выученной закономерности                  | Не выдаёт «схема / не схема», не блокирует                      |
| Calibration & Explanation      | Обычный код/обученные параметры | Калибровка, confidence band, reason codes                          | Не формирует юридическое основание                              |
| Mandatory Rule Evaluator       | Обычный код                     | Выполняет действующие обязательные правила независимо от модели    | Не отключается из-за низкого score                              |
| Prioritization Policy          | Обычный код                     | Top-K, abstain, conflict route, capacity и квоты                   | Не принимает решение по клиенту                                 |
| Control Sampler                | Обычный код                     | Вероятностная/стратифицированная выборка и inclusion probability   | Не позволяет очереди модели стать единственным источником меток |
| Review Queue / Case Management | Workflow                        | SLA, назначение, audit trail, показ источников                     | Не скрывает причины и версию модели                             |
| Специалист финмониторинга      | **Человек**                     | Проверяет, запрашивает сведения, принимает и обосновывает действие | Не обязан принимать рекомендацию модели                         |
| Outcome Collector              | Обычный код/данные              | Разводит expert label, эскалацию, исход и позднее подтверждение    | Не склеивает сигналы в один «истинный fraud»                    |
| Training Pipeline / Registry   | MLOps                           | Backtest, approval, подпись, lineage, champion/challenger          | Не выкатывает модель без gate владельца риска                   |

### Уровень автоматизации

- **Автоматически:** валидация, построение признаков, score, проверка области,
  применение обязательных правил, ранжирование, постановка в очередь,
  формирование контрольной выборки и аудит
- **Только рекомендация:** приоритет, score, reason codes и suggested route
- **Только человек:** оценка кейса, углублённое расследование, приостановка,
  отказ в проведении и иное действие, затрагивающее клиента
- Цена пропуска компенсируется обязательными правилами и exploration-квотой;
  цена ложного высокого score — фиксированным K, abstention и ручной проверкой

## Оцифровка документов

| контейнер               | тип                    | ответственность                                            | граница автоматизации                      |
| ----------------------- | ---------------------- | ---------------------------------------------------------- | ------------------------------------------ |
| Upload Quarantine       | Обычный код/ИБ         | AV, MIME/magic bytes, размер, CDR, изоляция                | Файл не достигает parser/model до проверки |
| Preprocessor            | Обычный код            | Разбиение, поворот, качество, конвертация                  | Не «исправляет» значения                   |
| Schema Registry         | Обычный код/метаданные | Типы, поля, версии, нормализация и правила                 | Изменение схемы проходит review            |
| OCR / Layout Extraction | **Модель**             | Тип, текст, таблицы, поля, confidence и координаты         | Не рассчитывает кредитный вердикт          |
| Validation & Routing    | Обычный код            | JSON Schema, форматы, арифметика, cross-document conflicts | Ошибка/нет источника -> ручная проверка     |
| Review UI               | Workflow               | Показывает оригинал, координату и исправления              | Критичные поля требуют подтверждения       |
| Андеррайтер             | **Человек**            | Подтверждает/исправляет поля, разбирает противоречия       | Модель не подменяет анализ заявки          |
| Result API              | Обычный код            | Записывает только валидированную подтверждённую версию     | Неподтверждённое не попадает в decisioning |

Обработка асинхронная. API загрузки возвращает `job_id`; повтор шага безопасен
по hash/version. Timeout не ведёт к частичному бизнес-результату. После
исчерпания retry документ получает статус `manual_required`

## Прогноз нагрузки

| контейнер                      | тип                     | ответственность                                           | граница автоматизации                  |
| ------------------------------ | ----------------------- | --------------------------------------------------------- | -------------------------------------- |
| Batch Ingestion & Data Quality | Обычный код             | Полнота интервалов, topology, дедупликация, known-at-time | Битый ряд не скорится как валидный     |
| Time-series Feature Store      | Обычный код/данные      | Lags, rolling и известные будущие события                 | Не включает фактическое будущее        |
| Forecast Service               | **Модель**              | Median/quantiles calls и workload                         | Не формирует смены                     |
| Staffing Optimizer             | Обычный код/оптимизация | SLA, Erlang, навыки, трудовые ограничения и стоимость     | Не меняет утверждённую смену сам       |
| Planning API/UI                | Workflow                | Сценарии, сравнение, override и approval                  | Публикация в WFM только после approval |
| WFM-планировщик                | **Человек**             | Проверяет события и утверждает расписание                 | Может выбрать baseline/ручной сценарий |
| Monitoring & Backtest          | Обычный код/аналитика   | Ошибка, калибровка, SLA, стоимость и drift                | Не продвигает champion без gate        |

Прогноз пакетный: weekly/daily для планирования и intraday refresh для
коррекции. Повтор создаёт новую версию, но не перезаписывает утверждённый план
